About the project

A gym management system prototype, built in the open.

My Gym explores how member registration and membership records could move from paper into a simple web-based workflow. The current repository is an early prototype, not a finished gym service.

Interface

Member registration demo

The Tailwind CSS front end includes a registration form to illustrate the details a gym might collect. Submissions are stored in the browser only; there is no live member account flow.

API

Member data endpoints

Project documentation describes a Node.js HTTP API and user records with names, subscription type, and trainer status. The current server response is a placeholder rather than a connected member database.

Project goal

Membership and equipment records

The project brief includes membership administration and equipment maintenance. Complete admin and maintenance workflows are not available in this prototype.
